# AbbayiOS
Audio book library with swiftui!

---
## Run

To run you must have [xcodegen](https://github.com/yonaskolb/XcodeGen) installed

```bash
xcodegen
```

The custom scripts folder may have missing permissions to execute, you can fix that by running:
```bash
chmod +x Scripts/*
```

Open the project with:
```bash
xed .
```

And run with:
```
cmd+r
```

Voilà
