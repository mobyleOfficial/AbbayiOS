# LibriVox Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let users search LibriVox from the Library, download a book chapter by chapter, and
start listening (streaming whatever isn't downloaded yet). File import keeps working unchanged.

**Architecture:** NetworkProvider (copied from iOSProjectSetup) becomes a framework target and
gains a delegate-based `DownloadProvider` for large files in the background. A LibriVox book is
one `AudioModel` with the synthetic identity URL `librivox://book/<id>`. Its chapters are separate
MP3s with cumulative `startTime`s, so "time" still means time within the whole book everywhere.
`Player` switches to `AVQueuePlayer` and maps book time to (chapter file, offset) through a pure
`BookTimeline`. `BookDownloadManager` drives the downloads and publishes per-chapter state to
the views.

**Tech Stack:** Swift 5 mode, SwiftUI, AVFoundation (`AVQueuePlayer`), Core Data (lightweight
migration), `URLSession` background download tasks, `Network` (`NWPathMonitor`), XcodeGen, XCTest.

**Spec:** `docs/superpowers/specs/2026-10-21-librivox-design.md`. Read it before any task.
Mockups: `.superpowers/brainstorm/18651-1792598022/content/entry-point-v3.html`,
`details-download.html`.

1. **Existing libraries after the upgrade:** an install with imported books from the v1 Core Data
   store must open with every book, position and chapter intact. Tested in Task 3,
   `test_v1Store_opensWithCurrentModel_keepsBooks`.

   `test_seek_acrossFileBoundary_loadsTargetChapterFile` and `test_saveTime_persistsBookTime`.
5. **Deleting a book mid-download, and relaunching mid-download:** deleting cancels the tasks and
   removes the files. Relaunching re-attaches to running tasks without duplicating them. Tested
   in Task 7, `test_delete_cancelsTasksAndRemovesDirectory` and
   `test_restore_doesNotDuplicateRunningTasks`.

**Interfaces:**
- Produces:
```swift
public enum DownloadEvent: Equatable {
    case progress(id: String, receivedBytes: Int64, expectedBytes: Int64?)
    /// `location` is a file the provider moved out of URLSession's temp area; the consumer must move it.
    case finished(id: String, location: URL)
    case failed(id: String, error: NetworkError)
}

public enum DownloadSessionKind {
    case foreground(URLSessionConfiguration = .default)   // tests / short-lived use
    case background(identifier: String)
}

public protocol DownloadProviderProtocol: AnyObject {
    var events: AsyncStream<DownloadEvent> { get }
    func start(_ request: NetworkRequestProtocol, id: String, allowsCellularAccess: Bool) throws
    func pause(id: String) async            // cancel(byProducingResumeData:), resume data kept on disk
    func resume(id: String, allowsCellularAccess: Bool) throws   // uses resume data if any, else throws NetworkError.invalidParams
    func cancel(id: String)                  // drops resume data too
    func runningIDs() async -> Set<String>   // re-attach after relaunch (task.taskDescription == id)
    func handleBackgroundEvents(completion: @escaping () -> Void)
}

public final class DownloadProvider: NSObject, DownloadProviderProtocol {
    public init(kind: DownloadSessionKind, resumeDataDirectory: URL)
}
```
- `NetworkError` gains `case fileSystem` (the move to a safe location failed) and
  `case httpStatus(Int)` (non-2xx). Map `URLError` the same way `NetworkProvider` already does
  (`cancelledRequest`, `connection`).

```swift
struct LibriVoxBook: Equatable, Identifiable {
    let id: String; let title: String; let authors: String; let descriptionText: String   // HTML stripped
    let language: String; let totalSeconds: Double; let archiveIdentifier: String
    let coverURL: URL                    // https://archive.org/services/img/<archiveIdentifier>
    let sections: [Section]
    struct Section: Equatable { let title: String; let seconds: Double; let listenURL: URL }
}
struct LibriVoxBookDetails: Equatable { let book: LibriVoxBook; let sectionBytes: [Int64]; var totalBytes: Int64 { sectionBytes.reduce(0, +) } }

protocol LibriVoxClientProtocol {
    func search(_ query: String) async throws -> [LibriVoxBook]
    func popular() async throws -> [LibriVoxBook]
    func details(for book: LibriVoxBook) async throws -> LibriVoxBookDetails
    func coverData(for book: LibriVoxBook) async -> Data?
}
final class LibriVoxClient: LibriVoxClientProtocol { init(network: NetworkProviderProtocol = NetworkProvider()) }

extension LibriVoxBookDetails {
    /// url = LibriVoxIdentity.bookURL(id:), title, artist = authors, albumName = title,
    /// duration = totalSeconds, librivoxID, totalBytes, chapters with cumulative startTime,
    /// remoteURL = listenURL, expectedBytes = sectionBytes[i]
    func audioModel(imageData: Data?) -> AudioModel
}
```
API facts, verified 2026-10-21:
- Base `https://librivox.org/api/feed/audiobooks/`. **Always** send `format=json&extended=1`
  (without `extended`, `url_iarchive` is missing). `title=^<prefix>` is a starts-with match.
  Plain `title=` without `^` is an exact match, and leading "The/A/An" are dropped from titles.
  `author=<last name>` works. `id=<n>` fetches one book. `limit` and `offset` work.
- No match → HTTP **404** with `{"error":"Audiobooks could not be found"}`. Treat it as `[]`.
- Numbers come as strings (`"playtime":"640"`, `"num_sections":"12"`). `totaltimesecs` is an Int.
- Sizes: `GET https://archive.org/metadata/<identifier>` → `files[]` with `name` and `size`
  (a string). Match on `listenURL.lastPathComponent`. A missing size counts as 0.
- `popular()` fetches these LibriVox ids in this order, concurrently (they are archive.org's
  most-downloaded LibriVox items): `["200","119","253","314","448","753","271","816","56","1557","59"]`.

**Files:**

  (call `downloads.remove(bookID:)` for LibriVox books)
- Test: `AbbayTests/BookDownloadManagerTests.swift` with a `MockDownloadProvider` (records calls,
  lets the test push `DownloadEvent`s)

**Interfaces:**
- Consumes: `DownloadProviderProtocol`, `LibriVoxIdentity`, `SaveAudioUseCaseProtocol`,
  `LoadAllAudiosUseCaseProtocol`, `ChapterPrioritizing`.
- Produces:
```swift
enum ChapterDownloadState: Equatable { case downloaded, downloading(fraction: Double), waiting }
struct BookDownloadState: Equatable {
    var chapters: [ChapterDownloadState]
    var isPaused: Bool
    var fraction: Double          // bytes-weighted over expectedBytes; falls back to chapter count when bytes are 0
    var isComplete: Bool { chapters.allSatisfy { $0 == .downloaded } }
}
protocol BookDownloadManagerProtocol: ChapterPrioritizing {
    var statesPublisher: AnyPublisher<[String: BookDownloadState], Never> { get }   // key = librivoxID
    func enqueue(_ book: AudioModel)          // starts chapters not yet on disk
    func pause(bookID: String)
    func resume(bookID: String)
    func remove(bookID: String)               // cancel all tasks, delete directory
    func restore()                            // at launch: reattach + restart
    func handleBackgroundEvents(completion: @escaping () -> Void)
}
final class BookDownloadManager: BookDownloadManagerProtocol {
    init(provider: DownloadProviderProtocol = DownloadProvider(kind: .background(identifier: "com.edyuto.Abbay.downloads"), resumeDataDirectory: …),
         root: URL = LibriVoxIdentity.defaultRoot, saveAudio: SaveAudioUseCaseProtocol = SaveAudioUseCase(),
         loadAll: LoadAllAudiosUseCaseProtocol = LoadAllAudiosUseCase())
}
```
Rules:
- Task id `"<bookID>#<chapterIndex>"`. **At most 2 chapters downloading per book**, started in
  chapter order. `prioritize` moves that chapter to the front of the queue, and starts it now if
  a slot is free or it's already the next one.
- Each task's `allowsCellularAccess` comes from the book's `allowsCellularDownload`. When it's
  false, a cellular-only device simply leaves the task waiting. That's the spec's "pause until
  Wi-Fi", provided by the system.
- `.finished`: move the file to `LibriVoxIdentity.localFileURL`, mark the chapter `.downloaded`,
  start the next one. `.failed(.cancelledRequest)` from a pause doesn't count as a failure.
  Any other failure puts the chapter back in `.waiting` and retries once, after 30 s.
- `pause`/`resume` persist `isDownloadPaused` through `SaveAudioUseCase`.
- `restore()`: for every LibriVox book in the library, mark chapters downloaded if their file
  exists. For books that aren't paused, start the missing chapters whose ids are not in
  `provider.runningIDs()`.
